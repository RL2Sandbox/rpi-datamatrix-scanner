# warehouse-vision-poc


Objective:
Develop a Raspberry Pi-based computer vision solution that:

1. Scans carton Data Matrix labels
2. Detects carton damage
3. Associates damage with carton identity
4. Uploads evidence to GCP
5. Supports automated incident reporting

Current Status:
✅ Data Matrix scanning
🔄 Damage model training
🔄 System integration
⬜ Automated reporting
